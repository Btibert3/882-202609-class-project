## TLDR

I recommend that you use this project to follow along with the in-class labs.  After cloning the repo, you can `pull` changes.  

> Do not edit files in this project.  It's not exactly read-only, but I would use this to follow along and to act as a reference for your own practice/homework or team project repository.  
> Sorting out git errors is part of the learning process!  Don't get frustrated.  While it's something we aim to avoid, inevitably you will face an issue.  It's not always as scary as it may seem, and I suspect that you will likely be saved from a bad mistake because you used a branch/commit!
